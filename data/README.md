# Data Directory

This folder is designated for storing documents, datasets, and knowledge bases for the Retrieval-Augmented Generation (RAG) system:

- Nutritional guidelines, RDA (Recommended Dietary Allowances) standards.
- Food calorie and macronutrient reference tables.
- Health dietary guidelines (e.g., WHO, ICMR, USDA).
- Processed vector indices or embeddings (when created).
